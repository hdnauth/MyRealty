# 01. 제품 기획 · 기능 명세

## 1. 제품 목표

"데이터를 보여주는 앱"이 아니라 **"내 부동산에 무슨 일이 일어나고 있는지 알려주는 앱"**.

1. **관심 물건 중심(Watchlist-first)** — 등록한 물건을 축으로 주변 거래, 유사 물건, 뉴스, 정책, 이벤트를 자동으로 끌어온다.
2. **조합 지표** — 가격 단독이 아니라 금리·소득·물가·공급·유동성과 엮은 지표로 "비싼지/싼지, 오를 여건인지"를 판단한다.
3. **AI 해석** — 숫자는 코드가 계산하고, AI는 그 결과를 해석·요약·질의응답한다(숫자를 지어내지 않도록 설계).
4. **푸시형 정보** — 내가 찾아보지 않아도 중요한 변화(신고가, 주변 청약, 규제 변경, 관련 기사)를 알려준다.

## 2. 핵심 사용 시나리오

| # | 시나리오 | 흐름 |
|---|---|---|
| S1 | 보유 아파트 모니터링 | 주소 검색 → 단지·평형 선택 → 매입가/대출 입력 → 매일 신규 실거래·추정 시세·전세가율 확인, 신고가 발생 시 알림 |
| S2 | 매수 후보 비교 | 후보 3~5곳 등록 → 비교 화면에서 평당가·월 부담·학군/교통 점수·가격 모멘텀 비교 → AI에게 "어디가 나은지 근거와 함께" 질문 |
| S3 | 빌라 전세 들어가기 전 점검 | 주소 입력 → 공시가격·건축물대장·주변 매매/전세 사례 → **깡통전세 위험 점수** 확인 |
| S4 | 토지·임야 관심 | 지번(PNU) 등록 → 지목·용도지역·공시지가 추이 → 인근 동일 지목 실거래(법정동 단위) → 도로·개발 관련 고시/뉴스 알림 |
| S5 | 시장 온도 체크 | 홈에서 "관심 지역 시장 온도계"와 주간 AI 브리핑 확인 |
| S6 | 정책 영향 확인 | 대출 규제·규제지역·토지거래허가구역 발표 시 → 내 물건 중 영향받는 것 자동 표시 + 요약 |

## 3. 정보 구조 · 화면

### 3.1 내비게이션

- **모바일**: 하단 탭 5개 — `홈` · `지도` · `내 물건` · `지표` · `AI`
- **PC(≥1024px)**: 좌측 사이드바 + 2단 레이아웃(지도 화면은 좌측 목록 / 우측 지도, 물건 상세는 좌측 요약 / 우측 차트·피드)

### 3.2 화면 목록

| 화면 | 주요 구성 |
|---|---|
| 로그인 | 이메일 입력 → 6자리 코드 입력(OTP). 허용 목록 외 이메일 차단 |
| 홈(피드) | 오늘의 요약 카드(AI 한 줄 브리핑), 내 물건 추정가 변동 요약, 알림 타임라인(실거래·뉴스·정책·이벤트), 시장 온도계 |
| 지도 | 네이버 지도 + 레이어 토글(실거래 마커/평당가 라벨, 법정동 가격변동 색상, 관심물건 핀, 청약·개발 이벤트, 지적도), 반경 원, 필터(유형·기간·면적·가격) |
| 내 물건 목록 | 카드 리스트(유형 아이콘, 추정가, 최근 변화율, 미확인 알림 수), 그룹/태그(보유·후보·관심) |
| 물건 등록 | 주소/지번 검색(도로명주소 API) 또는 지도에서 선택 → 유형 자동 추정 → 단지·동·호/평형 선택 → (선택) 매입가·매입일·대출·임대 정보 |
| 물건 상세 | 탭: `개요`(기본정보·건축물대장·토지이용·공시가격) · `시세`(실거래 차트, 추정 시세 밴드, 전세가율) · `주변`(유사 물건 comps, 반경 내 거래) · `소식`(뉴스·정책·이벤트) · `분석`(지표, AI 분석 카드) · `메모`(임장 노트·사진) |
| 비교 | 2~5개 물건 나란히 비교(표 + 레이더 차트), AI 비교 코멘트 |
| 지표 | 거시(금리·물가·M2·가계대출), 지역(가격지수·거래량·미분양·입주물량), 조합 지표, 커스텀 지표 빌더 |
| AI | 대화형 질의응답(내 데이터 기반), 주간/월간 리포트 보관함 |
| 캘린더 | 청약 일정, 금통위, 공시가격 발표, 입주, 관심 물건 관련 일정(만기·납부) |
| 설정 | 알림 채널(이메일/웹푸시), 다이제스트 시간, 알림 규칙, 허용 이메일, 데이터 내보내기 |

## 4. 기능 명세 (우선순위: P0 = MVP, P1 = 핵심 확장, P2 = 고급)

### 4.1 계정 · 인증
| 기능 | 설명 | 우선순위 |
|---|---|---|
| 이메일 OTP 로그인 | 이메일로 6자리 코드 발송 → 입력. PWA에서 매직링크는 다른 브라우저 컨텍스트로 열리는 문제가 있어 **코드 방식**을 기본으로 함 | P0 |
| 허용 목록 | 공개 가입 차단, 지정한 이메일(본인 + 가족 등)만 로그인 | P0 |
| 세션 유지 | 장기 리프레시 토큰, 기기별 로그아웃 | P0 |

### 4.2 관심 물건(Watchlist)
| 기능 | 설명 | 우선순위 |
|---|---|---|
| 주소 기반 등록 | 도로명주소 API로 검색 → 법정동코드·지번으로 PNU(19자리) 생성 → 좌표(지오코딩) 저장 | P0 |
| 유형별 식별 | 아파트/오피스텔: 단지 매칭(단지명+지번) · 빌라/단독: 지번+건물 · 토지/임야: PNU | P0 |
| 내 정보 입력 | 전용면적/평형, 층, 매입가·일, 대출(금리·만기), 임대(보증금·월세·만기) | P0 |
| 그룹/태그 | 보유 · 매수후보 · 관심 · 전세 거주 등 | P0 |
| 메모·사진 | 임장 노트, 사진 업로드(스토리지) | P1 |
| 체크리스트 | 유형별 매수 전 점검 항목(등기부 확인, 위반건축물, 용도지역, 도로 접면 등) | P1 |

### 4.3 시세 · 거래
| 기능 | 설명 | 우선순위 |
|---|---|---|
| 실거래 이력 | 매매/전세/월세, 해제(취소) 거래 표시, 직거래 구분 | P0 |
| 차트 | 평형별 가격 추이, 전세가율 추이, 거래량 막대 | P0 |
| 신고가/신저가 탐지 | 동일 단지·평형 기준 최고/최저 대비 | P1 |
| 추정 시세(AVM) | 유형별 모델로 현재가 추정 + 신뢰구간 ([04 문서](04-indicators-and-ai.md#3-추정-시세avm)) | P1 |
| 공시가격 추이 | 공동주택·개별주택 공시가격, 개별공시지가 | P1 |
| 현실화율 | 실거래(또는 추정가) / 공시가격 | P1 |

### 4.4 주변 · 유사 물건
| 기능 | 설명 | 우선순위 |
|---|---|---|
| 반경 내 거래 | 반경 N km 내 동일 유형 최근 거래 지도·목록 | P0 |
| 유사 물건(comps) | 유형·면적·연식·세대수·거리 기반 유사도 점수로 상위 N개 추천 | P1 |
| 상대 성과 | 내 물건 vs 유사 물건군 vs 시군구 지수의 기간 수익률 비교 | P1 |
| 입지 점수 | 역·학교·병원·대형마트까지 거리 기반 점수 | P2 |

### 4.5 뉴스 · 정책 · 이벤트
| 기능 | 설명 | 우선순위 |
|---|---|---|
| 뉴스 자동 연결 | 물건별 키워드(단지명·동·시군구·인근역·조합명)로 뉴스 수집 → AI가 관련도·카테고리·영향 판단·요약 | P1 |
| 정책 피드 | 국토부·금융위 보도자료, 규제지역·토지거래허가구역 변경, 대출 규제 → 영향받는 내 물건 표시 | P1 |
| 청약·분양 이벤트 | 청약홈 분양 공고 중 내 물건 반경/시군구 내 건 알림 | P1 |
| 경제 이벤트 | 금통위 기준금리 결정, 공시가격 발표, 통계 발표 일정 | P1 |
| 개발 이벤트 | 정비사업 단계 변화, 도시계획 고시, 교통 개통(수동/반자동 등록 포함) | P2 |
| 경·공매 | 온비드 공매 물건 중 관심 지역·유형 | P2 |

| 기능 | 설명 | 우선순위 |
|---|---|---|
| 거시·지역 지표 대시보드 | 기준금리, 주담대 금리, CPI, M2, 가계대출, 지역 가격지수, 거래량, 미분양, 입주물량 | P1 |

| 시나리오 시뮬레이터 | 금리 ±1%p, 가격 ±10% 시 월 상환액·LTV·DSR·순자산 변화 | P1 |

|---|---|---|
