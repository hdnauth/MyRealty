# 02. 데이터 소스

> 서비스명·엔드포인트·트래픽 한도는 제공 기관 사정으로 바뀌므로, 활용신청 시점에 각 포털에서 최신 명세를 확인한다.
> 아래 "키"는 발급 필요 여부, "주기"는 본 앱의 권장 수집 주기.

## 1. 식별자 체계 (모든 데이터를 엮는 열쇠)

| 식별자 | 형식 | 용도 |
|---|---|---|
| 법정동코드 | 10자리 (시도2 + 시군구3 + 읍면동3 + 리2) | 지역 단위 집계, 실거래 API의 `LAWD_CD`(앞 5자리 = 시군구) |
| PNU(필지고유번호) | 19자리 = 법정동코드(10) + 산 여부(1: 일반=1, 산=2) + 본번(4) + 부번(4) | 토지·건축물대장·공시지가·토지이용계획 조회의 공통 키 |
| 단지코드 | 공동주택관리정보시스템(K-apt) 단지코드 | 아파트 단지 기본정보·관리비 |
| 좌표 | WGS84 경위도 (지도), 필요 시 EPSG:5179/5186 변환 | 지도 표시, 반경 검색(PostGIS) |

**등록 흐름**: 도로명주소 검색 → 응답의 법정동코드·지번(본번/부번/산 여부)으로 PNU 생성 → 지오코딩으로 좌표 획득 → 아파트/오피스텔이면 단지 매칭.

**행정구역 개편 지역(전남광주통합특별시)의 신·구 코드**: 도로명주소·공공데이터포털(실거래가·건축물대장)은 새 시군구 코드(예: 광양시 `12190`, 순천시 `12150`)로만,
브이월드(토지특성·토지이용계획·개별공시지가·공동주택가격)는 아직 옛 코드(전라남도 `46xxx`, 광주광역시 `29xxx`)로만 답한다(2026-09 확인).
읍면동·리 이하 5자리와 지번은 같으므로 앞 5자리만 바꿔 조회한다 — 시군구 **이름**으로 옛 코드를 찾는 표가
`services/etl/src/myrealty_etl/codes.py`(`LEGACY_SGG_BY_NAME`)와 `apps/web/src/lib/legacy-codes.ts` 에 있다. 브이월드가 새 코드로 답하기 시작하면
새 코드 조회가 먼저 성공하므로 코드를 고치지 않아도 된다. 다른 지역이 개편되면 같은 표에 추가한다.

## 2. 부동산 거래 · 가격

| 데이터 | 제공처 | 키 | 주기 | 비고 |
|---|---|---|---|---|
| 아파트 매매 실거래가(상세) | 국토교통부, 공공데이터포털(data.go.kr) | ○ | 일 1회 | `LAWD_CD`(시군구 5자리) + `DEAL_YMD`(YYYYMM) 요청. 해제 여부·해제일, 거래유형(중개/직거래), 등기일자 등 포함 |
| 아파트 전월세 실거래가 | 〃 | ○ | 일 1회 | 보증금·월세·계약기간·갱신요구권 사용 여부 |
| 연립다세대 매매 / 전월세 | 〃 | ○ | 일 1회 | 빌라 |
| 단독/다가구 매매 / 전월세 | 〃 | ○ | 일 1회 | **지번 일부 비공개** → 필지 단위 정확 매칭 불가, 법정동 단위 비교 |
| 오피스텔 매매 / 전월세 | 〃 | ○ | 일 1회 | |
| 토지 매매 | 〃 | ○ | 일 1회 | 지목(임야 포함)·용도지역·거래면적. **지번 일부 비공개** |
| 상업업무용 부동산 매매 | 〃 | ○ | 주 1회 | 상가·업무시설 |
| 분양권·입주권 전매 | 〃 | ○ | 주 1회 | |
| 공동주택 공시가격 / 개별주택가격 | 국토부·부동산공시가격알리미, 브이월드(VWorld) 속성조회 | ○ | 연 1회(4~5월) + 이의신청 반영 | |
| 개별공시지가 | VWorld / 국가공간정보포털 | ○ | 연 1회(5~6월) | 토지·임야 가치 판단의 기준선 |
| 가격지수·전세지수·수급동향 | 한국부동산원 R-ONE 부동산통계 Open API | ○ | 주/월 | 주간 아파트 매매·전세가격지수(시군구), 매매수급지수 |

**수집 제약과 대응**
- 실거래 신고 기한이 계약 후 30일이므로 **최근 1~2개월은 과소 집계**된다 → 최근 3개월치를 매일 재수집(upsert), 화면에 "집계 중" 표시.
- 해제 거래는 삭제하지 않고 `is_canceled`로 표시, 통계에서는 제외.
- 개발계정 일일 호출 한도(서비스별 상이)를 고려해 **관심 부동산이 있는 시군구 + 인접 시군구만 우선 수집**, 전국 백필은 야간에 천천히. 운영계정 전환(활용 사례 등록) 시 한도 상향 가능.

## 7. 지도 · 주소

| API | 제공처 | 용도 |
|---|---|---|
| Maps JavaScript API v3 (Dynamic Map) | 네이버 클라우드 플랫폼(NCP) Maps | 지도, 마커, 클러스터링, 폴리곤/GeoJSON, 커스텀 타일 |
| Geocoding / Reverse Geocoding | NCP Maps | 주소 ↔ 좌표 (결과는 DB에 캐시) |
| Static Map | NCP Maps | 이메일 리포트용 지도 이미지 |
| 도로명주소 검색 API | 행정안전부 도로명주소 개발자센터(juso.go.kr) | 주소 자동완성, 법정동코드·지번 획득 |
| 연속지적도(필지 경계) | 브이월드 데이터 API `LP_PA_CBND_BUBUN`(`attrFilter=pnu:=:…`) | 토지·임야 등 필지 영역을 지도에 테두리로 표시. 웹이 처음 볼 때 받아 `parcels.boundary` 에 캐시(180일, 못 찾으면 7일 뒤 재시도) |
| 교통·생활 POI | 국가철도공단/지자체 역 정보, 학교알리미·NEIS 학교기본정보, 공공 의료기관 정보 | 입지 점수(P2) |

> NCP Maps는 2025년 상품 개편으로 스크립트 인증 파라미터·API 도메인이 바뀌었으므로(신규 키는 `ncpKeyId` 기준) 발급 콘솔의 가이드를 따른다. 웹 서비스 URL(도메인) 등록 필수: `localhost`, 배포 도메인 모두 등록.
