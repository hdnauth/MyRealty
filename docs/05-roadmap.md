# 05. 로드맵 · 리스크

> **구현 현황(2026-09)**: Phase 0~5 전체를 구현했다. 아래 체크 표시는 완료 항목이며, 남은 항목은 "향후 과제"에 정리했다.

## 1. 단계별 마일스톤 (1인 개발, 주당 10~15시간 기준)

### Phase 0 — 준비 (1주)
- [x] API 키 발급 ([02 문서 체크리스트](02-data-sources.md#8-발급-체크리스트)), 공공데이터포털 활용신청(승인까지 수일 소요 가능 → 가장 먼저)
- [x] 모노레포 스캐폴딩: `apps/web`(Next.js), `services/etl`(Python/uv), `supabase/`
- [x] Supabase 프로젝트 생성, PostGIS·pgvector 확장, 법정동코드·행정경계 시드
- [x] CI(lint·typecheck·test), Vercel 연결, GitHub Actions 시크릿 등록
- [x] **기술 검증(PoC)**: 네이버 지도 + 마커 클러스터링 1,000개 성능, VWorld 지적도 타일 오버레이, 실거래 API 1개 시군구 호출·파싱

### Phase 1 — MVP (3주): "내 부동산과 주변 거래를 본다"
- [x] 이메일 OTP 로그인, 허용 목록, 보호 라우트
- [x] 반응형 레이아웃(하단 탭/사이드바), PWA 매니페스트
- [x] 주소 검색 → 관심 부동산 등록(아파트·빌라·오피스텔·단독·토지·임야), PNU·좌표 생성
- [x] 실거래 ETL(매매·전월세, 관심 시군구, 최근 3개월 재수집 + 백필), 단지 매칭, 지오코딩
- [x] 부동산 상세: 개요 + 실거래 차트 + 전세가율
- [x] 지도: 관심 부동산 핀, 반경 내 거래 마커(평당가 라벨), 필터
- **완료 기준**: 휴대폰 홈 화면에서 로그인 → 내 아파트의 최근 거래를 차트·지도로 확인

### Phase 2 — 연결 (3주): "주변과 소식을 자동으로 연결한다"
- [x] 건축물대장·K-apt·토지이용계획·토지특성·공시가격 수집
- [x] 유사 부동산(comps) + 상대 성과
- [x] 뉴스 수집 + AI 분류(구조화 출력, Batch) + 부동산별 소식 탭
- [x] 청약홈 분양·금통위·공시가격 일정 이벤트 + 캘린더
- [x] 알림 엔진(신규 거래·신고가·해제·주변 청약·관련 뉴스) + 알림함 + 이메일 다이제스트 + 웹푸시

- **완료 기준**: 매일 아침 다이제스트 메일로 내 부동산 관련 거래·기사·이벤트를 받음

### Phase 3 — 해석 (3주): "조합 지표로 판단한다"

### Phase 3 추가 — 입지·개발 지표 (요청 반영)

- [x] `ADMIN_EMAILS` 관리자, 관리 화면(개요·사용자·사이트 설정·시스템·작업 기록), 1인당 AI 한도, 공지 배너, 회원 탈퇴

### 향후 과제
- 온비드 공매 알림, 도시계획 고시(토지이음) 반자동 추적
- 임장 사진 업로드(오브젝트 스토리지 연동)
- 법정동 경계 폴리곤 기반 색상 지도(choropleth)
- 가족 공유(읽기 전용 권한), 뉴스 임베딩(pgvector) 기반 유사 기사 묶기
- R-ONE·KOSIS 통계표 코드 검증 후 기본 활성화

## 2. 예상 운영 비용 (월, 개인 사용 기준)

| 항목 | 예상 | 비고 |
|---|---|---|
| Vercel | 무료(Hobby) | 개인·비상업 용도 |
| Supabase | 무료 → 데이터가 커지면 Pro | 무료 티어 DB 용량 한도 내에서 관심 지역만 수집하면 충분. 전국 10년치 실거래를 쌓으면 유료 필요 |
| GitHub Actions | 무료 한도 내 | 비공개 저장소는 월 실행 시간 한도 확인 |
| 네이버 클라우드 Maps | 무료 제공량 내 예상 | 상품별 무료 제공량·과금 기준 확인 |
| 공공 API · 네이버 검색 API | 무료 | 일일 호출 한도 존재 |
| Claude API | 사용량 비례 | Batch·프롬프트 캐싱·월 예산 상한으로 통제 |
| 이메일 발송 | 무료 티어 | |

## 3. 리스크와 대응

| 리스크 | 영향 | 대응 |
|---|---|---|
| 공공 API 일일 호출 한도 | 전국 수집 지연 | 관심 지역 우선, 쿼터 추적·이월, 운영계정 전환 신청 |
| API 명세 변경·서비스 교체 | 수집 중단 | 수집기별 계약 테스트(샘플 응답 스냅샷), 실패 시 알림, 원본 `raw` 보관 |
| 실거래 신고 지연(30일) | 최근 통계 과소 | 최근 3개월 재수집, UI에 "집계 중" 표기, 지표에서 최근월 가중 낮춤 |
| 지번 마스킹(토지·단독) | 필지 단위 비교 불가 | 법정동·지목·면적대 단위 비교, 공시지가 배율 활용 |
| 단지명 표기 불일치 | 거래 누락·오매칭 | 정규화(공백·괄호·영문), 별칭 테이블, 지번 교차 검증, 수동 매칭 UI |
| 뉴스 약관·저작권 | 법적 문제 | 제목·요약·링크만 저장, 본문 크롤링 금지, 원문 링크 이동 |
| AI 환각 | 잘못된 판단 | 숫자는 도구 결과만 사용, 출처·기준일 표기, 구조화 출력, 면책 문구 |
| AVM 오차 | 과신 | 신뢰구간·근거 comps 표시, 오차 추적 대시보드 |
| 민감 정보(대출·임대) | 유출 | RLS, 허용 목록 로그인, 서비스 롤 키 서버 전용, 백업 암호화 |
| iOS PWA 제약 | 푸시·로그인 | OTP 코드 로그인, 홈 화면 설치 안내, 이메일 다이제스트 병행 |
