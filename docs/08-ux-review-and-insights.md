# 08. UX 재검토 · 공공데이터 · 거시 인사이트

> 2026-09 검토. 편의성(입력·탐색 부담을 줄이기)과 전문성(숫자의 근거·맥락·해석) 두 축으로 앱 전체를 다시 보고,
> 국내 부동산 앱들이 무엇을 주는지, 사용자가 실제로 무엇을 묻는지, 공공데이터와 거시지표로 무엇을 더 답할 수 있는지 정리한다.
> 앱 이름·기능은 공개된 일반 기능 수준으로 적었다(세부 사양은 앱 업데이트로 바뀔 수 있음).

## 1. 국내 부동산 앱 기능 리뷰

| 앱 | 사람들이 쓰는 이유(핵심 기능) | MyRealty 에 주는 시사점 |
|---|---|---|
| 네이버 부동산 | 가장 많은 **매물(호가)**, 단지 정보·시세·실거래를 한 화면에서 | 호가는 공개 API가 없다 → 우리는 **실거래·신고 기반의 '확정된 가격'과 해석**에 집중하고, 매물은 외부 링크로 넘긴다 |
| 호갱노노 | 지도 위 **평당가 라벨**, 관심 단지 **실거래 알림**, 입주물량·인구이동·학원가 등 레이어, 단지 이야기 | 지도 평당가·알림은 이미 있음. **공급(입주)·인구이동 레이어**와 "이 단지를 본 사람이 같이 본 단지" 대신 **유사 단지 비교**로 대응 |
| 아실(아파트실거래가) | **여러 단지 가격 그래프 겹쳐 보기**, 매물 증감, **갭투자·외지인·법인 매수**, 입주물량, 가격 순위 | 비교 화면에 **가격 추이 겹쳐 보기**가 가장 큰 공백. 실거래 상세의 **매수자 구분(개인/법인)·직거래·등기일자**로 외지인/법인/미등기 지표를 만들 수 있음 |
| KB부동산 | **KB시세**(대출 한도 기준), 주간 KB 지수, 매수우위지수 | 은행 대출 산정 기준이 시세이므로 **"대출 기준 시세 ≠ 실거래"**를 설명하고 우리 AVM 구간을 함께 제시. 매수우위는 부동산원 **매매수급지수**로 대체 |
| 부동산지인 | **수요·공급**(입주량 vs 적정 수요), 시장 강도, 거래량 분석 | 공급압력 지표는 있음. **적정 수요(인구·가구 기반) 대비 입주량**으로 해석을 쉽게 |
| 리치고 등 AI 시세 앱 | AI 추정가·미래 가격 예측, 입지 점수, 저평가 여부 | 예측 숫자 하나보다 **구간·신뢰도·근거(comps)**를 보여 주는 편이 전문적이다(이미 AVM 구간·백테스트 있음). "저평가"는 **유사 단지 대비 격차의 과거 평균 이탈**로 정량화 |
| 디스코·밸류맵 | 토지·건물 실거래, 건축물대장·토지이용계획·지적도, 경공매 | 토지·임야·상가 사용자는 **필지 정보 + 공시지가 배율**이 핵심. 지적도·용도지역 레이어가 다음 과제 |
| 청약홈 | 분양 공고·경쟁률·당첨가점 | 주변 분양 알림은 있음. **분양가 vs 주변 시세(안전마진)**, 경쟁률 추이를 붙이면 수요 신호가 된다 |
| 안심전세(HUG) | 전세 계약 전 시세·위험 확인, 악성 임대인 정보 | 깡통전세 점검은 있음. **보증보험 가입 가능 여부(공시가격 × 인정비율)**와 역전세 위험을 임차인·임대인 모두에게 |

**공통 패턴**: 잘 쓰이는 앱은 ① 한 화면에서 "얼마·싼가·오를까"를 답하고 ② 알림으로 다시 부르고 ③ 비교(단지·지역·기간)를 쉽게 한다.
MyRealty 의 차별점은 **"내가 등록한 부동산을 중심으로, 거시·지역·단지 지표를 한 줄의 해석으로 연결"**하는 것이다 — 매물 앱과 경쟁하지 않는다.

## 2. 사람들이 실제로 묻는 것

| 사용자 | 가장 자주 묻는 질문 | 필요한 화면·기능 |
|---|---|---|
| 1주택 실거주 | 우리 집 지금 얼마? 동네보다 잘 올랐나? 보유세·대출 이자는? | 추정 시세 + 구간, 전고점 대비, 상대 성과, 금리 변동 → 월 이자, 보유세 |
| 갈아타기·매수 준비 | 후보 A/B 중 어디? 적정가는? 지금 사도 되나? 대출은 얼마까지? | **후보 비교(가격 추이 겹쳐 보기)**, 매수 가능 금액(DSR·LTV), 시장 해석, 층·향별 가격 차 |
| 임대인 | 전세 만기에 보증금 돌려줄 수 있나? 재계약 시세는? | 역전세 위험(현재 전세 vs 계약 당시), 신규·갱신 전세가 차이, 만기 알림 |
| 임차인 | 이 전세 안전한가? 보증보험 되나? 월세로 바꾸면? | 깡통전세 점수, 보증 인정 한도, 전월세 전환 비교 |
| 투자 | 갭은? 외지인·법인이 들어오나? 공급은? | 전세가율·갭, 외지인/법인 매수 비중, 입주·인허가 파이프라인 |
| 토지·임야 | 이 땅 얼마쯤? 무엇을 지을 수 있나? 주변 개발은? | 공시지가 배율 시세, 용도지역·규제, 개발사업 반경 |

→ 모든 화면이 결국 다섯 질문에 답해야 한다: **얼마인가 · 싼가 비싼가 · 앞으로 · 내 자금으로 되나 · 위험은**.

## 3. 화면별 UX 재검토

원칙
1. **입력은 한 번, 추론은 앱이**: 호수에서 층, 주소에서 유형·평형, 공공데이터에서 면적(반영 완료). 사용자가 모르는 숫자(반경 m, 만원 단위)를 묻지 않는다.
2. **숫자 하나에 맥락 하나**: 모든 가격 옆에 "무엇 대비"(전고점·1년 전·지역·유사 단지)를 붙인다.
3. **근거를 숨기지 않는다**: 표본 수(n건), 기준일, 출처, 추정 구간. 표본이 적으면 흐리게 + "참고".
4. **해석을 먼저, 차트는 근거로**: 지표 화면은 해석 카드 → 차트 순(반영 완료).

| 화면 | 발견 | 개선안 | 우선 |
|---|---|---|---|
| 등록 | 층·동/호 분리 입력, 만원 단위 입력 | 한 칸 동·호 + 층 자동, 금액 자연어(**반영**) | 완료 |
| 등록 | "주변 탐색 반경(m)" 숫자 입력 | 500m / 1km / 2km **칩**, 유형별 기본값 표시 | P1 |
| 등록 | 그룹이 셀렉트, 뉴스 키워드가 기본 노출 | 그룹은 칩(보유·매수 후보·관심·전월세), 키워드는 "고급 설정"으로 접기 | P1 |
| 등록 후 | 수집 전 빈 화면이 많음 | "처음 수집은 내일 아침 · 지금 볼 수 있는 것" 안내 카드(건축물대장·공시가격·입지는 즉시) | P1 |
| 홈 | 첫 줄이 알림 건수 나열 | **보유 자산 변화(이번 달 추정가 ±)** + 시장 해석 한 줄 + 오늘 거래, 알림은 그 아래 | P1 |
| 상세 개요 | 6개 숫자가 같은 무게 | 맨 위 **추정 시세(구간·신뢰도)** 하나를 크게, 나머지는 보조. 전고점 대비(**반영**) | P1 |
| 상세 개요 | 층·향에 따른 가격 차 없음 | 같은 평형 **층별 거래 산점도**(저층/중층/고층 중위), 내 층 표시 | P1 |
| 시세 탭 | 단지 하나만 봄 | **평형 간·단지 간 가격 추이 겹쳐 보기**(비교 화면과 공유) | P1 |
| 비교 | 표 + AI 코멘트 | 가격 추이 겹쳐 보기, 평당가 격차의 과거 평균 대비 위치(저평가 신호) | P1 |
| 지표 | 한 페이지가 매우 김, 용어(PIR·월부담지수) 설명 부족 | 섹션 탭(해석·가격·부담·금리·도구), 용어 옆 **?** 툴팁 | P1 |
| 지도 | 칩이 한 줄에 많음 | 유형·기간은 드롭다운, 레이어는 별도 버튼. **입주물량·용도지역·지적도** 레이어 | P2 |
| 전역 | ㎡/평 혼용 | 설정에서 **기본 단위(㎡/평)** 선택, 전 화면 일관 표기 | P1 |
| 전역 | 하단 탭 '관심 부동산' | 5글자 라벨이 390px 폭에서 한 줄로 들어가는 것 확인. 더 좁은 기기(320px)는 추후 확인 | 확인 |

| 주택건설 실적(인허가·착공·분양·준공, 시군구) | 국토부 통계누리 / KOSIS | ○ | 3~4년 뒤 공급의 **선행 지표**. 인허가 급감 지역 = 몇 년 뒤 공급 부족 |
| 미분양·**준공 후 미분양** | 국토부 → KOSIS | ◐(코드 확인 전 비활성) | 준공 후 미분양 증가는 가격 약세의 강한 신호 |
| 공동주택 공시가격·개별주택가격·개별공시지가 | 국토부·부동산공시가격알리미 / VWorld | ● | **현실화율**(공시/시세) → 보유세 변화 예고, 토지 **공시지가 배율** |
| 공동주택관리정보(K-apt) | 국토부 | ◐ | **관리비(㎡당)**, 난방방식, 주차 — 실거주 비용 비교 |
| 토지이용계획·토지특성·지적도 | 국토부 VWorld | ● | 용도지역별 허용 용적률, 도로 접면 → 토지 활용도. 지도 레이어 |
| 도시계획(UPIS)·고시(토지이음) | 국토부 | ○ | 지구단위계획·정비구역 지정 등 **개발 이벤트** 반자동 추적 |
| 토지거래허가구역·규제지역 | 국토부 고시 | ○(수동) | 관심 부동산이 규제 대상인지, 발표 시 알림 |
| 청약홈 분양정보·경쟁률 | 한국부동산원 | ◐ | **분양가 vs 주변 시세**(안전마진), 경쟁률 추이 = 신규 수요 강도 |
| 매입자 거주지별·연령대별 매매 | 한국부동산원 R-ONE | ○ | **외지인 매수 비중**(투자 수요 유입), 30대 매수 비중(실수요) |
| 주간 매매·전세 지수, 매매수급지수, 전월세전환율 | 한국부동산원 R-ONE | ◐(코드 확인 전 비활성) | 주간 속보성, 매수우위, **전환율 − 대출금리**(월세 vs 매수 유인) |
| 소유권이전 등기 통계(생애최초·연령·지역) | 법원 등기정보광장 | ○ | 생애최초 매수 증가 = 실수요 회복 |
| 전세보증 사고·분양보증 평균 분양가 | HUG | ○ | 지역별 보증사고 = 빌라 전세 위험, 분양가 추이 |

## 5. 거시 지표와 연결하는 방법

### 5.1 흐름으로 본다
```
[돈의 값]  기준금리 → 시장금리(국고채·금융채) → 주담대 금리 ─┐
[돈의 양]  M2 · 가계대출 증가 · 은행 대출태도 ──────────────┼→ [구매력] 월부담지수·PIR → [거래] 거래량·매수우위 → [가격] 지수·신고가
[수요]     인구·가구 이동 · 외지인/생애최초 매수 · 기대(CSI) ─┘                                         ↑
[공급]     인허가(−4년) → 착공(−3년) → 분양(−2.5년) → 입주 · 미분양 ──────────────────────────────────┘
[전세]     전세가율 · 전환율 · 갱신/신규 차이 → 갭 → 매매 전환 압력 / 역전세
```
각 층의 지표를 **선행 · 동행 · 후행**으로 나눠 "지금 어디쯤인가"를 말한다.

| 구분 | 지표 | 대략의 시차(경험적) | 상태 |
|---|---|---|---|
| 선행 | 국고채 3년 − 기준금리(금리 기대), 주담대 금리 변화, 가계대출 증가율, 거래량(3M/12M), 매매수급지수, 주택가격전망 CSI, 인허가·착공(공급은 수년 선행) | 수개월~수년 | 금리·거래량 **반영**, 나머지 P1 |
| 동행 | 가격지수, 신고가/하락 거래 비율, 전세가율 | — | **반영** |
| 후행 | 미분양(특히 준공 후), 공시가격, 경매 진행 건수 | 수개월~1년 | P2 |

### 5.2 지금 '시장 해석' 카드가 판단하는 규칙 (`lib/insights.ts`)
| 규칙 | 조건 | 해석 |
|---|---|---|
| 대출 금리 | 주담대(신규) 6개월 변화 ≥ ±0.2%p | 하락 = 구매력 개선(월 상환 변화율 함께 표시) |
| 금리 기대 | 국고채 3년 − 기준금리 ≤ −0.15%p / ≥ +0.5%p | 인하 기대 / 인상·인하 지연 |
| 부담 수준 | 월부담지수의 과거 분위 ≥ 80% / ≤ 30% | 고점권(상승 여력 제한) / 실수요 진입 쉬움 |
| 거래 선행 | 최근 3개월 거래 ÷ 1년 평균 ≥ 1.3 / ≤ 0.7 | 가격보다 먼저 움직임 / 관망 |
| 확산도 | 신고가 비율 ≥ 20% / 하락 거래 ≥ 50% | 상승 확산 / 조정 우세 |
| 실질 가격 | 명목 1년 변화 vs 물가 보정 변화, 실질 고점 대비 | 명목 전고점이어도 구매력 기준 위치 |
| 유동성 | M2 대비 가격의 고점 대비 ≤ −15% | 통화량 대비 낮음(받침) |
| 전세 | 전세가율 1년 ±2%p | 상승 = 매매 전환 압력 / 하락 = 역전세 주의 |
| 공급 | 24개월 입주/재고 ≥ 8% / ≤ 2% | 과잉 / 부족 |

임계값은 초기값이다. 지역별 과거 데이터로 "해당 신호 이후 6개월 가격 변화"를 백테스트해 조정한다(온도계 백테스트와 같은 틀).

### 5.3 다음에 추가할 신호 (데이터 → 산식 → 쓰임)
1. **역전세 위험(단지·평형)**: 현재 전세 중위 ÷ 24개월 전 전세 중위 − 1 < 0 → 만기 도래 임대인에게 "보증금 차액 약 X억" 알림.
2. **신규·갱신 전세 괴리**: 같은 단지·평형 신규 계약 중위 − 갱신 계약 중위 → 전세 수요 압력.
3. **전환율 스프레드**: 전월세전환율 − 주담대 금리 → 양수가 크면 월세 선호·매수 유인.
4. **외지인·법인 매수 비중**: 매입자 거주지 / 매수자 구분 → 투자 수요 유입 경보.
5. **미등기 신고가**: 신고가 중 90일 지나도 등기일자 없는 비율 → 신고가 신뢰도 표시.
6. **공급 파이프라인**: 인허가·착공(시군구) 시차 이동 합 vs 적정 수요(가구 증가·멸실 대체) → "3년 뒤 공급 부족/과잉".
7. **상대 저평가**: 내 단지 평당가 ÷ 유사 단지군 평당가의 z-score(과거 3년) → 격차가 평소보다 크면 "상대 저평가" 후보.
8. **금리 민감도**: 내 대출·후보 가격에 대해 금리 ±0.5%p, ±1%p → 월 상환·DSR 표(시뮬레이터를 개요 탭에 요약).
9. **정책 이벤트 연구**: 규제지역 해제·대출 규제 발표 전후 거래량·가격 변화(개통 전후 분석과 같은 방식).

### 5.4 톱다운 브리핑 구성 (주간 리포트·홈)
전국(금리·유동성·심리) → 시도(수급·공급) → 시군구(온도계·해석) → 단지(거래·전고점) → **내 부동산(추정가·손익·위험)**
한 단계씩 좁혀 "큰 흐름이 내 집에 어떻게 닿는지"를 3~5줄로 쓴다. 숫자는 도구·지표 결과만 인용한다(AI 규칙 유지).

## 6. 우선순위 (모두 구현 — 0. 반영 현황 참고)

| 순서 | 항목 | 이유 |
|---|---|---|
| 완료 | 동·호/층 자동, 금액 자연어, 전고점 대비, 시장 해석 카드, 용어 통일, 지도 수정 | 입력 부담·첫인상 |
| P1 | 비교·시세 탭 **가격 추이 겹쳐 보기**, 개요 **추정 시세 강조 + 층별 가격**, 지표 **섹션 탭·용어 툴팁**, 반경/그룹 칩, ㎡/평 설정 | 가장 자주 쓰는 질문(얼마·싼가)에 바로 답함 |
| P1 | 실거래 상세 필드(매수자 구분·직거래·등기일자·갱신요구권) 저장 → 법인/직거래/미등기/갱신 괴리 지표 | 추가 API 없이 기존 수집에서 확장 |
| P1 | R-ONE·KOSIS 통계코드 확정 → 매매수급·전환율·미분양·외지인 매수 활성화, 해석 규칙 추가 | 선행 지표 보강 |
| P2 | 건축인허가·주택건설 실적 → 공급 파이프라인, 등기정보광장(생애최초), CSI·가계대출·대출태도 | 거시 흐름 완성 |
| P2 | 지도 입주물량·용도지역·지적도 레이어, 분양가 vs 시세 | 토지·신축 사용자 |

## 7. 주의
- 호가(매물) 데이터는 공개 API가 없어 다루지 않는다. 실거래는 신고 후 최대 30일 지연된다(최근 1~2개월 과소 집계).
- 해석 규칙은 경험적 임계값이며, 지역 표본이 적으면 흔들린다. 표본 수와 기준일을 항상 함께 표시한다.
- 투자 권유가 아니라 판단 보조다. 모든 화면·리포트에 이 원칙을 유지한다.
