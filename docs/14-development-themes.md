# 14. 개발·테마

개발사업 메뉴(`/projects`, 메뉴 이름 "개발·테마")를 "등록된 목록"에서 **전국 정비사업과 개발 테마를 탐색하는 허브**로 바꾼 기록.
테마는 같은 성격의 장소를 한 렌즈로 묶어 **필터 목록 + 분포 + 최근 변화 + 내 부동산과의 연결 + 지도**로 보여 주는 틀이다.

| 탭 | 질문 | 주 데이터 |
|---|---|---|
| 정비사업 | 어디서 재개발·재건축이 어느 단계까지 왔나, 내 주변·지켜보는 구역은? | 서울·경기·부산·인천 시스템, 시군구 파일, 국토부 전국 통합 |
| 재건축 후보 | 아직 구역 지정 전인 오래된 단지 중 사업성 재료가 좋은 곳은? | 단지 준공연도, 건축물대장(용적률·대지면적), 용도지역 |
| 교통 호재 | GTX·신설 노선 역은 언제 열리고, 역세권 시세·개통 효과는? | 철도 시드(계획·착공·최근 개통), 실거래 |
| 규제 | 내 부동산이 토지거래허가·지구단위계획·정비구역에 걸리나? | 브이월드 용도구역 경계, 필지 토지이용계획 |
| 공급 | 시군구별로 앞으로 얼마나 나오나? | 정비사업 공급 예정 세대수, 청약홈 입주 예정 |

## 1. 개선 전 문제

- 운영 DB 의 정비구역·철도/도로 사업이 **0건**이었다. 수집 경로가 GeoJSON/CSV·관리자 수동 등록뿐이라 아무도 채우지 않았다.
  그래서 입지 탭의 개발 요인, 재개발·재건축 카드, 지도 레이어가 사실상 비어 있었다.
- 화면은 최근 200건을 이름·단계 한 줄로 늘어놓기만 했다 — 지역·유형·단계로 거를 수 없고, 내 부동산과의 관계도 보이지 않았다.
- 지도는 모든 사업을 큰 라벨로 한꺼번에 그려, 데이터가 수백 건만 돼도 화면을 덮는다.

공통 처리(`collectors/zone_common.py`)

- **단계**: 출처마다 다른 표기("조합(시행자)", "17)사업시행자지정", "관리처분계획", "정비구역지정 전", "준공(2022-04-28)")를 9단계 진행도로 맞춘다. 해산·청산·이전고시·준공·해제는 9(완료, 해제는 `attrs.canceled`). 날짜가 붙어 오면 `stage_date` 로 쓴다.
- **유형**: 재개발·재건축·도시정비형재개발·주거환경개선·가로주택·소규모재건축/재개발·리모델링·지역주택조합.
- **이력**: 단계가 바뀌면 `zone_stage_history` 에 한 줄. 첫 수집은 남기지 않는다. 한 목록에 같은 시군구·같은 이름이 두 번 나오면 `#2` 를 붙여 서로 덮어쓰지 않는다(가짜 단계 변경 방지).
- **위치 정밀도** `attrs.geo`: boundary(경계) · address(지번) · complex(같은 이름 단지) · place(장소 검색, 대략) · dong(법정동 중심, 대략). 대략 위치는 화면에 "위치 대략"으로 표시한다.
- **호출량**: 실행마다 새로 위치를 찾는 횟수 상한 900(`ZONES_LOCATE_BUDGET`), 못 찾은 곳은 30일 동안 다시 찾지 않는다. 첫 배포 뒤 며칠에 걸쳐 채워진다.
- **해외 러너**: 서울 정보몽땅·부산은 웹 국내 중계(`/api/relay`)로 다시 부른다. 경기·인천·공공데이터포털 파일은 세션·POST 가 필요해 중계하지 못한다 — 막히면 국내 PC 에서 `uv run myrealty zones` 를 돌린다.
- 브이월드 데이터마켓의 전국 정비구역 경계(연속주제도 UD602)는 로그인 다운로드라 자동 수집하지 않는다. 서울 밖 경계는 `import-geo` 로 넣을 수 있다.

## 3. 화면 (`/projects`)

### 정비사업 탭

- **내 관심 부동산 주변**: 부동산마다 반경 1km 진행 중 구역 수·인가 이후 수·가장 가까운 구역, 3km 안 계획 철도.
- **필터**: 단계 묶음(초기·조합설립·인가·이주/착공·완료, 기본은 완료 제외) · **팔로우** · 시도 → 시군구 · 유형 · 검색. 정렬: 최근 변화·진척·세대수·내 부동산 가까운.
- **단계 분포**, **단계별 가격 프리미엄**(구역 연결 단지 vs 같은 시군구 아파트 중위, 최근 1년), **최근 단계 변화**.
- **구역 상세**(`?zone=`): 9단계 막대와 단계별 확인 사항, 공급 예정 세대수·시행자·소유자/조합원 수·용도지역, 구역 단지(없으면 주변 300m)의 평당가,
  **단계 변화 전후 가격**, 단계 변경 기록, **팔로우(단계 알림)**, 지도·동네 이야기·출처 링크, 출처·위치 정밀도 표시.

### 재건축 후보 탭

준공 25/30/35년 이상 · 100세대 이상 아파트(수집된 시군구). 용적률(현재/용도지역 상한, 서울 조례 참고값)·**여유**·**세대당 대지지분**·평당가·이미 구역 지정 여부,
정렬: 종합(여유·지분·연식 단순 합)·여유·지분·연식·평당가. 건축물대장·용도지역은 매일 `rebuild` 단계가 60곳씩(180일 주기) 채운다.

### 교통 호재 탭

`data/rail_projects.json` 시드(GTX-A/B/C, 신안산선, 동북선, 월곶판교선, 인덕원동탄선, 위례신사선, 서부선, 대장홍대선, 최근 개통 노선 등 21개 구간·109역).
역 좌표는 브이월드 역 정보(같은 이름 역은 힌트 시군구로 고름), 신설역은 같은 이름 역 앞 시설이나 법정동 중심(위치 대략). 노선은 역을 이은 개략선.
역마다 500m 아파트 수·평당가, 내 부동산까지 거리, 개통 역은 반경 1km 단지 평당가의 **개통 전후 12개월 변화**와 시군구 지수 변화.
개통 목표는 자주 바뀌므로 시드의 `as_of` 와 함께 참고 자료로 표시하고, 관리자가 직접 등록·삭제할 수 있다. 시드 파일이 바뀌면 다음 실행에서 다시 넣는다.

### 규제 탭

내 관심 부동산마다 **토지거래허가구역·지구단위계획구역·정비구역** 해당 여부(필지 토지이용계획 + 구역 경계), 지역별 허가구역·지구단위계획구역 면적(겹치는 지정은 합집합).
경계는 매일 `regulations` 단계가 관심 부동산·진행 중 구역이 있는 0.1° 격자만 25일 주기로 받는다(브이월드 `LT_C_UQ141`, 응답 피처 id 는 요청마다 바뀌어 고시 정보+형상 해시를 키로).
부동산 상세 개요에도 해당하면 "규제·계획 구역" 카드가 뜬다.

### 공급 탭

시군구별 입주 예정(36개월, 청약홈) · 정비 2~4년(관리처분~착공 공급 예정 세대수) · 정비 4~8년(조합설립~사업시행인가), 내 지역 먼저.
세대수 미상 구역은 물량에서 빠지므로 구역 수를 함께 보인다.

### 지도 · 단지 상세 · 알림

- 지도 "개발사업" 레이어: 화면 안 사업만, 넓게 보면 단계 색 점(숫자 = 단계). 확대하면 **정비구역 경계**와 **철도 노선(계획은 점선)** 을 `/api/map/overlays` 로 그 범위만 받아 그린다.
  새 레이어 **토지거래허가구역·지구단위계획구역**. `/map?layers=permit,district_plan` 으로 켠 채 열 수 있다.
- 단지 상세: 연결된 정비구역(단계 막대).
- 알림 `zone_stage`: 관심 부동산 1km 안 + **팔로우한 구역**의 단계 변화. 사업시행·관리처분·착공은 즉시 푸시.

## 4. 분석

- **구역 ↔ 단지**(`zone_complexes`): 경계 안(inside) → 경계 없는 재건축·리모델링은 600m 안 같은 이름(name) → 120m 안 가장 가까운 아파트(near).
- **단계 효과**(`zone_stage_effects`): 사건일(단계 변경 감지일, 또는 출처가 준 단계 날짜 — 대전 "준공(2022-04-28)" 등) 전후 12개월 연결 단지 평당가 중위 변화 vs 시군구 자체 지수 변화.
  거래가 전후 3건 이상, 사건 후 3개월이 지나야 계산한다. 단계 이력이 쌓일수록 늘어난다.
- **단계별 프리미엄**: 화면에서 바로 계산(최근 1년, 단순 비교라 지역·연식 차이가 섞임 — 참고용).
