# 15. 무로그인 이용 · 화면 구성

일반 사용자가 앱을 열자마자 쓸 수 있도록, 로그인은 **꼭 필요한 기능에서만** 요구한다.

## 이용 단계

| 단계 | 구분 방법 | 할 수 있는 것 |
|---|---|---|
| 방문자 | 세션 쿠키 없음 | 모든 화면 열람: 지도·단지 상세·시장 지표·개발·테마·동네 이야기 읽기, 주소 검색 |
| 기기 게스트 | 이메일 없는 `users` 행 + 이 기기의 세션 쿠키(90일, 접속마다 연장) | 관심 부동산 등록·메모·포트폴리오·비교, 게시판 구독, 커스텀 지표, 웹푸시 알림, AI 답변 신고 |
| 회원 | 이메일 6자리 코드로 가입 | 위 전부 + 동네 이야기 글·댓글·공감·투표·신고·사진·거주 인증, AI 질문·분석·비교·리포트, 이메일 요약, 여러 기기 |

- 게스트는 **무언가를 처음 저장할 때** 만들어진다(`ensureUser`). 화면을 보기만 하면 DB에 아무것도 남지 않는다.
  같은 IP에서 한 시간에 20개까지만 만들 수 있다.
- 회원 전용 기능은 `requireMember` 가 `/login?next=…&why=member` 로 보낸다(화면은 `MemberGate` 안내 카드).
- 가입: 처음 쓰는 이메일이면 **게스트 행에 이메일을 채워** 그대로 회원이 된다. 이미 가입한 이메일이면 게스트의 관심 부동산·메모·알림·구독·푸시를
  그 계정으로 옮기고 게스트를 지운다(`mergeGuest`).
- 정리: 살아 있는 세션이 없는 게스트(90일 넘게 미접속·데이터 삭제)는 ETL `cleanup` 이 매일 지운다. 게스트에게는 이메일·AI 리포트를 보내지 않는다.
- 세션이 폐기·정지됐는데 쿠키만 남은 경우 페이지는 `/api/auth/reset` 으로 쿠키를 지우고 방문자로 다시 보여 준다(`pageUser`).

## 시작 화면과 메뉴

- `/`: 관심 부동산이 있으면 요약 홈, 없으면(방문자 포함) **지도**로 바로 이동. 방문자의 지도 첫 중심은 최근 매매가 가장 많은 시군구.
- 모바일 하단 탭: **지도 · 관심 · 시장 · 동네 · 전체**. 전체(`/menu`)에 모든 기능과 계정·가입 안내를 모았다.
- PC 사이드바: 기본(지도·관심 부동산·동네 이야기) / 시장 분석 / 내 자산 묶음, 아래에 계정 또는 간편 가입 버튼.
- 메뉴 구성은 `components/shell/nav-config.ts` 한 곳에서 관리한다.

## 운영 메모

- 마이그레이션 `0016_guest_accounts.sql`(이메일 nullable). 관리 화면 통계·사용자 목록은 기본으로 가입 사용자만 세고, 목록에서 "기기 게스트"를 따로 볼 수 있다.
- 주소·지도 조회 API(`/api/address*`, `/api/map/*`, `/api/parcel/boundary`)는 방문자에게도 열려 있다. 외부 API 호출량이 늘면 IP 기준 제한을 검토한다.
