# 16. 한눈에 보기 · 눈여겨볼 지표 · 보기 방식 · 지역 수집 요청

> 2026-10. 제품 포지셔닝 검토 뒤 반영. 컨셉은 **"누구에게나 같은 화면인데 전문적이고, 다른 앱에서는 잘 안 보이는 지표가 나에게 실제로 도움이 된다"**이다.
> 사용자 유형을 앞세운 문구나 순서 바꾸기("우리 집", "사고 싶은 집")는 하지 않는다. 사용자가 직접 넣은 정보(대출·보증금·내 자금)가 있을 때만 답에 반영된다.

## 1. 상세 화면 구조(8탭 → 5탭)

| 탭 | 내용 | 예전 탭 |
|---|---|---|
| 요약 | 한눈에 보기(5가지 질문) → 시세 카드 → 눈여겨볼 지표 → 근거 카드(보증금 점검·내 자산·자금 계산·금리·층별·규제·재개발·건물·AI 분석·주변 지도) | 개요 + 분석 |
| 시세 | 가격 추이 → 비슷한 단지와 비교(가격 위치·1년 상승률·유사 단지) → 평형별 추이 → 거래 내역 → 주변 거래 | 시세 + 주변 |
| 입지 | 생활편의 점수·개발 요인(점수 검증은 전문 보기) | 입지 |
| 소식 | 뉴스·주변 이벤트 → 동네 이야기 | 소식 + 이야기 |
| 메모 | 임장 메모·체크리스트 | 메모 |

- 예전 주소(`?tab=nearby`·`analysis`·`talk`)는 `proxy.ts` 가 307 로 새 위치(`?tab=price#compare`, `?tab=overview#ai`, `?tab=news#talk`)로 보낸다 — 알림·메일·북마크 링크 유지(`lib/item-tabs.ts`).
- 시세 탭 맨 위에 섹션 바로가기(가격 추이 · 비교 · 거래 내역 · 주변 거래). 주변 거래 "전체 보기"는 `nall=1`.

## 2. 한눈에 보기(`lib/brief.ts` `buildBrief`)

질문과 순서는 모두 같다: **지금 얼마? · 싼 편일까, 비싼 편일까? · 시장 흐름은? · 자금 계획은? · 조심할 점은?**
숫자는 이미 계산된 값(추정 시세·유사 단지 z·시장 해석·전세 점검)만 쓰고, 이 모듈은 문장·판정만 만든다(순수 함수, 단위 테스트).

| 질문 | 답의 근거 | 자료가 부족할 때 |
|---|---|---|
| 지금 얼마 | 추정 시세(구간·신뢰도) → 같은 평형 6개월 중위 → ㎡당 중위 × 면적. 매입가를 넣었으면 손익 | 1년 거래 3건 미만은 "참고용" |
| 싼가 비싼가 | 유사 단지 대비 격차의 **평소(3년 평균) 대비 위치**(z ≤ −1 싼 편, ≥ 1 비싼 편) | 1년 상승률 격차 → 토지는 공시지가 배율 → 전고점 대비 |
| 시장 흐름 | 시군구 시장 해석 판정 + 지금 온도 + 요인(과거 적중률 높은 순) + **켜진 신호의 과거 적중률(무작정 찍기와 나란히)** | 지역 지표가 없으면 "계산 전". 채점 기간 24개월 미만이면 적중률을 보이지 않는다 |
| 자금 계획 | 넣은 정보에 따라: 세 들어 삶 → 보증금 ↔ 전세 시세(갱신요구권 5%) / 대출·받은 보증금 → 월 상환·시세 대비 비율·금리 +1%p / 그 밖 → 내 자금으로 필요한 대출(부대비용·LTV·DSR 40%)과 최대 가격 | 필요한 입력을 그 자리에서 받는다(내 자금 폼·수정 링크) |
| 조심할 점 | 깡통전세 비율·보증보험 한도(공시가격×126%)·전세 시세 하락, 역전세, 대출 70%↑, **1년 10%↑ 하락**, 토지거래허가, 거래 부족, 미등기 신고가 20%↑, 입주 물량 | "눈에 띄는 위험 없음 + 무엇을 점검했는지" |

색: 위험 판정(나쁨·주의·안전)만 글자에 색을 쓴다. 가격 방향은 점 색으로만(문장을 칠하면 경고처럼 읽힌다).
단지 상세(`/complexes/[id]`, 방문자도 열람)에도 같은 카드가 있다.

## 3. 눈여겨볼 지표(`notableSignals`)

실거래 세부 항목과 조합 지표 중 **이 부동산·지역에서 평소와 다르게 나타나는 것만** 최대 4개, 출처와 함께.

| 지표 | 조건 | 출처 |
|---|---|---|
| 이 집 층 가격 차이 / 층에 따른 차이 | 내 층 ±3%↑ / 저층·고층 차 5%p↑ | 실거래 층 |
| 신규 vs 갱신 전세(단지) | ±5%↑, 신규·갱신 각 3건↑ | 전월세 계약구분 |
| 신규 vs 갱신 전세(시군구) | ±5%↑ (단지 자료 없을 때) | 〃 |
| 등기 안 된 신고가 | 10%↑ | 실거래 등기일자 |
| 법인 매수 비중 | 5%↑ 이고 1년 +2%p↑ | 매수자 구분 |
| 직거래 비중 | 12%↑ | 거래유형 |
| 물가 반영 실질 가격 | 고점 대비 −10%↓ | 자체 지수 ÷ CPI |
| 소득 대비 월 상환 부담 | 과거 분위 80%↑ 또는 30%↓ | 실거래·금리·소득 |

지역 공통 지표는 같은 시군구 모든 집에 똑같이 나오므로 가중치 0.6 — 그 집에만 해당하는 지표가 먼저 온다.

## 4. 내 자금(`users.settings.finance`)

가용 현금·연소득(만원)·LTV(40~80%, 기본 50%). 설정 › 내 자금, 요약 카드 안, 단지 화면, 매수 후보 등록 화면에서 넣는다(게스트는 이 기기). 부대비용은 1주택 개략(6억 이하 1.5%, 9억 이하 2.5%, 초과 3.8% — 취득세·교육세·중개보수). 스트레스 DSR·지역별 한도 규제는 반영하지 않는다고 화면에 밝힌다.

## 5. 기본 보기 · 전문 보기(`view_mode` 쿠키)

| 화면 | 기본 보기 | 전문 보기 |
|---|---|---|
| 요약 | "숫자 더 보기" 접힘 | 펼침 |
| 시세 비교 | 격차 문장 | + 표준편차(z) |
| 입지 | 짧은 설명, 점수 검증 숨김 | 가중·산식 설명 + 점수 검증(회귀) |
| 시장 지표 요약 | 판정 · 이유 3가지(과거 적중률 순) · 신뢰도 한 줄 · 쉬운 숫자 4개(거래량은 집계 중인 이번 달 제외 3개월 평균), 나머지는 "숫자로 더 보기" | 시장 해석 전체 · 온도계 구성(z) · 조합 지표 · 규칙별 과거 성적 |

설정 › 보기 방식, 각 화면 아래 전환 링크.

## 6. 수집 전 지역(지도)

수집은 관심 등록된 시군구(`collect_targets`)부터 한다. 지도에 거래가 하나도 없고 동네 수준으로 확대했으면 가운데 좌표를 브이월드로 역지오코딩(약 1km 격자 메모리 캐시)해 그 시군구가

- 수집 전 → "이 지역 데이터 모으기"(기기 게스트로 남김, **사용자당 하루 3곳**) → `collect_targets` 를 켜고 `region_requests` 에 기록. 켜진 수집 대상이 `REGION_TARGET_CAP`(기본 40) 이상이면 `pending` 으로만 남긴다(공공 API 일일 한도 보호, 운영자가 켬)
- 수집은 켜졌지만 아직 거래가 없음 → "모으기 시작했어요 · 다음 매일 수집 뒤 표시"

모바일은 시트가 접혀 있어도 지도 위에 작은 카드로 보인다. 방문자(관심 부동산 없음)는 목록 위에 "단지를 누르면 무엇까지 보이는지" 안내(닫으면 이 기기에서 숨김).

## 7. 그 밖

- 단지·부동산 시세 카드에 **네이버 부동산 매물 링크**(`m.land.naver.com/search/result/{동} {단지명}` — 대개 단지 화면으로 바로 이동). 호가는 공개 API가 없어 외부로 넘긴다.
- 등록 화면: 고른 그룹에 필요한 입력만 보인다(전월세 거주 → 보증금·만기, 보유 → 매입·대출·임대, 매수 후보 → 자금 정보). 숨긴 칸도 값은 그대로 보내 수정 때 지워지지 않는다.

## 8. 점검한 사용 흐름(로컬, 운영 DB의 공공데이터 테이블 사본 + 데모 계정)

방문자 첫 지도 · 수집 전 지역 요청(대전·광주·부산, 4번째는 하루 제한) · 단지 상세(수원 영통, 김포 — 지역 지표 없음, 순천 — 1년 −31%) · 내 자금 입력 · 매수 후보 등록 · 전월세 거주(보증금 있음/없음) · 보유+세 놓음(역전세) · 보유+대출 · 임야 · 예전 탭 주소 · 지표 기본/전문 보기 · 모바일 390px / PC.
이 과정에서 고친 것: 요청 직후 성공 문구가 사라지던 문제, 그룹을 바꿨다 돌아오면 자금 입력이 지워지던 문제, 채점 6개월짜리 적중률(67% vs 67%) 표시, 큰 하락이 위험으로 안 잡히던 문제, 표본 1~2건 신규·갱신 전세 차이, 세입자·집주인 답의 서로 다른 색, 스트리밍 때문에 HTTP 리다이렉트가 안 되던 예전 탭 주소.
