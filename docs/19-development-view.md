# 19. 개발 현황 보기 — 정비구역 · 철도/도로 · 규제

> 요청(2026-10): 재개발·재건축·도로 건설 등 개발 현황을 지도 레이어에서 볼 수 있는지, 다른 화면이 있는지 검토하고 제안대로 모두 구현.
> 주기 수집은 자주 바뀌지 않는 자료이므로 시스템 부하가 최소가 되게.

## 1. 검토 결과(구현 전)

| 항목 | 상태 |
|---|---|
| 보는 곳 | 지도 레이어 '개발사업'(정비구역 점·경계 + 철도) · 토지거래허가 · 지구단위계획, 별도 화면 **개발·테마**(`/projects` — 정비구역·재건축 후보·교통·규제·공급 탭), 부동산·단지 상세의 구역 카드 |
| 데이터 | 운영 DB 정비구역·철도/도로·규제구역 **모두 0건** — 수집 단계가 10-03 커밋에서 매일 수집에 처음 들어갔고, 매일 수집은 앞 단계에서 60분 제한에 걸려 거기까지 가지 못했다 |
| 도로 | 표는 `road`·`ic` 를 받지만 자동 수집 출처 없음(관리자 직접 등록뿐) |
| 화면 연결 | 개발·테마 '지도' 버튼이 좌표만 넘겨 '📍 거래 위치'로 표시, 레이어도 켜지지 않음(토지·상가 유형은 레이어가 꺼져 구역이 안 보임) |
| 레이어 | 재개발·재건축·철도·도로가 한 체크박스, 단계 색 범례 없음, 단계·종류 구분 불가 |
| 부하 | 지도 페이지가 전국 사업을 최대 3,000건 한꺼번에 내려보냄, 정비구역 출처(서울·경기·부산·인천·국토부)를 매일 전부 다시 읽음 |

> 후속(2026-10): 서울 밖 구역 경계·초기 후보지는 토지이용계획 필지로 — [20 문서](20-zones-live-far.md).

## 3. 지도

- 레이어 분리: **🏗 정비구역(재개발·재건축)** / **🚆 철도·도로 사업**. 예전 저장값 `projects` 는 두 레이어로 바꾼다.
  유형별 추천: 아파트(정비구역·철도·역·학교), 빌라·단독(정비구역), 오피스텔(역·철도), 토지(지적도·용도지역·토지거래허가·철도).
- 정비구역 보기(레이어 패널, 이 기기에 저장): **단계 색 범례 겸 켜고 끄기**(초기·조합설립·인가·이주·착공), **재개발 / 재건축 / 소규모·기타**.
- 사업 카드: 종류·단계(6/9)와 **9단계 진행 막대**, '단계 이력·가격 효과 보기'(정비구역) · '교통 호재 상세 보기'(철도).
- 깊은 링크: **`/map?zone=<id>`**, **`/map?infra=<id>`** — 그 사업으로 이동, 해당 레이어를 켜고, 정보 카드를 열고, 구역 경계를 굵게 강조.
  개발·테마의 정비구역·교통 탭 '지도' 버튼과 화면 위 '지도' 버튼(탭에 맞는 레이어)이 이 링크를 쓴다.
- 사업 점은 **화면 범위 안만 레이어가 켜졌을 때** 받는다(`/api/map/projects`, 넓게 보면 생략) — 페이지가 전국 목록을 내려보내지 않는다.
- 대체 지도 전환 때 네이버 지적도·교통 레이어 해제가 예외를 던져 화면 오류가 나던 문제를 막았다(토지 유형은 지적도가 기본이라 드러났다).

## 4. 계획 도로(도로 건설 예정)

- 출처: 브이월드 **도시계획(도로) `LT_C_UPISUQ151`** — 지자체 도시계획정보체계(UPIS)의 결정·고시 도로. 속성에 집행 상태(집행완료/미집행/부분집행),
  등급(광로·대로·중로·소로), 기능(주간선·보조간선·집산·국지), 고시 번호(날짜 포함), 연장·면적이 있다.
- 받는 것: **미집행·부분집행이면서 광로·대로·중로(폭 12m 이상)** — 도시계획으로 정해졌지만 아직 다 만들지 않은 도로. 소로(골목)와 집행완료는 뺀다.
  (수원 일대 시험: 전체 7,276건 중 714건, 수집 지역 전체 2,144건 — 중로 1,241 · 대로 285 · 광로 45)
- 지도: 철도·도로 레이어에서 **동네 수준으로 확대했을 때** 도로 부지를 칠한다(미집행 주황, 부분집행 갈색). 개통 목표 시기는 자료에 없다.
- 고속도로·국도 신설(한국도로공사·국토부 사업)은 위치가 있는 공개 API 를 찾지 못했다 — 필요하면 철도처럼 시드 파일이나 관리자 등록으로.

| 좌표 이어 찾기(`locate`) | 매 실행, 찾을 곳이 없으면 즉시 끝 |
| 단지 연결 · 단계 효과 | **바뀌거나 새로 위치를 찾은 구역이 있을 때만**(아니면 30일) |
